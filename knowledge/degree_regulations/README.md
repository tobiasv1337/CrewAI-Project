# Degree Regulation PDFs

Drop TU Berlin regulation PDFs here so the Degree Regulations Specialist can
answer source-backed questions with RAG.

Recommended contents:

- Allgemeine Studien- und Prüfungsordnung / AllgStuPO PDFs
- Program-specific Studienordnung / Prüfungsordnung / StuPO PDFs
- Subfolders per degree program are supported

The index is rebuilt automatically when PDFs are added, removed, or changed.
Generated vector data is stored in CrewAI's local storage, not in this folder.

Current limitation: text-based PDFs work best. Scanned PDFs or graphical
Regelstudienplan tables may need an OCR/Docling enhancement later.
